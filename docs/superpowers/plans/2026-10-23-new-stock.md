# New-car Stock Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add new PS3/PS4 stock from every US dealer to the report, merged with pre-owned listings per model and sorted cheapest first.

**Architecture:** Fetch the dealer list once, then make one `filteredStockCars` call per dealer covering both model codes. Tag each car with its dealer, split the cars by model code, and merge them with the pre-owned listings into price-sorted lines per model section. Everything stays in `polestar_check.py`, following its existing `fetch_vehicles` / `vehicle_url` style.

**Tech Stack:** Python 3.14 via the `uv run` script shebang, `requests`, and `pytest` against the real API with no mocks.

**Spec:** `docs/superpowers/specs/2026-10-23-new-stock-design.md`

## Global Constraints

- Stock API: `https://pc-api.polestar.com/eu-north-1/preconfigured-cars/`, no auth. The `Origin: https://www.polestar.com` header is enough.
- `market` is `"us"`, `customerType` is `"B2C"`, `source` is `Preconfigured`, and the model filter is `filterTypeId` `"4"`.
- Model codes: PS3 is `"359"` and PS4 is `"814"`. PS2 gets no new-stock query.
- Detail URL: `https://www.polestar.com/us/stock-cars/<slug>/<pno34 url-encoded>/?year=<modelYear>&structureweek=<startStructureWeek>&partnerid=<partnerId>`, with slugs `polestar-3` and `polestar-4-coupe`.
- New price is `cashPriceData.discounted.totals.grandTotal.paymentTotal.paymentTotalPrice.value`. MSRP is the same path under `listPrice`.
- Requests are serial: no threads, no retries.
- A failed dealer request prints exactly one line to stderr, `warning: <dealer name>: <error message>`, and the run continues.
- Run the tests with: `uv run --python 3.14 --with pytest --with requests pytest -q`

## Review Focus

1. A dealer request returning GraphQL `errors`: warn, then skip that dealer. Covered by `test_fetch_new_vehicles_warns_and_skips_failing_dealer` (Task 1).
2. A dealer with more stock than one page holds: every page is fetched. Covered by `test_fetch_new_vehicles_pages_through_every_result` (Task 1).
3. A pno34 containing runs of spaces: the URL must percent-encode them as `%20`, not `+`. Covered by `test_stock_url_matches_site_format` (Task 2).
4. A model with zero new stock: its section still prints, with pre-owned lines only. This follows from the existing header-count test plus PS2 having no new query (Task 3).
5. Sorting across new and pre-owned: each section's lines must be non-decreasing by price. Covered by `test_report_sections_are_sorted_cheapest_first` (Task 3).

def test_fetch_new_vehicles_pages_through_every_result(dealers):
    # Find a dealer with at least 2 cars, then fetch it again 1 car per page
    everything = pc.fetch_new_vehicles(dealers, STOCK_CODES)
    counts = collections.Counter(c["dealer"]["partnerId"] for c in everything)
    partner_id, count = counts.most_common(1)[0]
    if count < 2:
        pytest.skip("no dealer currently lists 2+ new cars")
    dealer = [d for d in dealers if d["partnerId"] == partner_id]

    one_per_page = pc.fetch_new_vehicles(dealer, STOCK_CODES, page_size=1)

    assert len(one_per_page) == count

### Task 3: Merged, price-sorted report per model

- Modify: `polestar_check.py`: replace `pretty_print_vehicle_results` with two formatters that return `(price, line)`; rewrite `__main__`.

**Interfaces:**
- Consumes: `fetch_vehicles`, `fetch_dealers`, `fetch_new_vehicles`, `vehicle_url`, `stock_url`, and `MODELS[...]["pno3"]`.
- Produces:
  - `preowned_line(car_model: str, vehicle: dict) -> tuple[int, str]`. Price is `price.dealer`. The line keeps today's format, prefixed with the tag padded to 9 characters: `CPO` when `cycleState == "CertifiedPreOwned"`, otherwise `Pre-owned`.
  - `new_line(car_model: str, car: dict) -> tuple[int, str]`. The line is `f"{'New':<9} ${price:<6,} ({msrp:,}) - {modelYear} {engine}, {color} - {dealer city:<15} {url}"`. `engine` and `color` are the `content` names whose `featureType` is `"Engine"` and `"Color"`. Prices are converted to `int`.
- `__main__`: run one national sweep, `fetch_new_vehicles(fetch_dealers(), [codes of MODELS entries that have a pno3])`. Then, for each model, gather its pre-owned lines plus the new cars whose `content` `"Model"` code equals its `pno3`. Sort by price and print the header as `"{name} ({count})"`, the same as today.
